## 具体设计

- 系统设置：左侧分类导航，右侧当前分类；分为“账号与调度 / 请求与稳定性 / 自动任务 / 日志与用量 / 兼容性”，保持全部配置可达。
- 常用配置：初始提供日常调整项，支持收藏/取消收藏；仅在本浏览器保存字段标识，不缓存配置值、凭证或密钥。
- 全局搜索匹配名称、说明、配置键、常见别名和选项中文名；结果标明原分类。提供清除搜索、无结果状态。
- 切换分类、搜索、查看待保存项不丢草稿。分类显示未保存数量；底部保存栏统一保存所有分类的修改，校验失败自动定位对应字段。
- 详情收敛：主视图显示中文标签、用途和控件，配置键/默认值等放入可展开详情，环境锁和待应用状态保持清晰。
- 登录授权移到账号管理的可展开区域；兼容旧 `#authorization` 链接。管理账号独立页面、头像直达；快速接入独立入口，保留 API 地址复制与密钥/模型链接。
- 桌面采用双栏，窄屏切换为横向分类导航和单列设置；保留键盘可达、标签关联、焦点反馈与减少动态效果偏好。
