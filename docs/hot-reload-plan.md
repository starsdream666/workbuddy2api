2. 保留文件持久化、字段白名单、环境变量优先级、管理员鉴权/CSRF、修订号冲突保护及未知字段/密钥原样保留。

## 生效语义与范围

- 热重载入口是管理设置 API 保存；本期不监听外部文件变化。外部文件改动继续通过修订号识别，不能悄悄覆盖。
- 请求体上限、超时和兼容性采用请求/操作开始时的配置；已开始的流式响应不因修改被主动中断。
- 选号、并发、积分保底等在后续调度判断生效，不重建账号池，不清空余额、在途数、冷却或熔断状态。
- 冷却/熔断时长变化影响之后的触发；既有冷却截止时间保留。冻结兜底时长影响之后新触发的冻结，既有冻结截止时间保留（代码确认当前以 frozenUntil 存储）。
- 会话开关和 TTL 在后续会话操作生效；保留有效绑定，更新 GC 间隔，不重复创建清理循环。
- 定时任务开关/时点/巡检间隔保存后重新排程。已开始的一轮正常结束；不因每次配置更新重复执行启动全量巡检。保留按渠道覆盖和不支持能力缓存，手动维护仍与定时任务串行。
- 日志参数安全更新：保留计数及可保留的历史；缩小内存只裁剪超出容量的旧记录，磁盘轮转/备份遵循新策略，历史清理不承诺可撤销。
- 环境变量控制的字段继续只读。监听端口、文件目录、认证存储、Redis 连接、产品线路由拓扑等不在页面白名单内的启动配置不纳入热重载。
- 一次保存先完整校验并准备，再持久化并发布。准备/写入失败时运行配置不变；提交阶段不执行可能失败的外部请求。成功响应必须反映实际应用版本。
